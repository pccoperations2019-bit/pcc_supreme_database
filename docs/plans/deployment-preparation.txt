Files prepared
scripts/deployment/New-Release.ps1
  Packages only tracked application source plus the built public/build assets.
  Refuses dirty tracked source or a different commit. Excludes .env, SQL dumps,
  uploads, storage, vendor, node_modules, .git and Windows launcher scripts.
  Writes a ZIP, SHA256 sidecar and per-file manifest. These are release
  candidates, not independently signed artifacts or deployable installations.

scripts/deployment/Initialize-DeploymentServer.ps1
  One-time administrator setup on 192.168.146.11. Creates a NEW directory:
  C:\ProgramData\SUPREME-Deploy
  Refuses to replace an existing directory. SYSTEM/Administrators control the
  root and controller. supreme_deploy gets read/execute there and Modify only
  on incoming and staging. No live application ACL, SSH setting, Git remote,
  service, scheduled task, database or environment file is changed.

scripts/deployment/Stage-Release.ps1
  Verifies SHA256, repository, full commit, manifest and every file. Rejects
  unsafe/duplicate ZIP paths, links and oversized archives. Uses a staging
  lock and never overwrites an existing release. Compares migration source
  hashes without querying the database. Writes a stage-report.json with
  activationAllowed=false. Does not install dependencies, run Artisan,
  change live code, apply migrations or restart workers.
  A failed partial extraction stays in its unique staging directory for
  inspection; it is never treated as successfully staged or auto-deleted.

scripts/deployment/Get-DeploymentReadiness.ps1
  Reads the protected server config, checks explicit PHP 8.4 and extensions,
  records presence of environment and dependencies without reading secrets.

scripts/deployment/Get-ProductionOperations.ps1
  Read-only administrator inventory of relevant process identities, matching
  services/tasks, fixed-disk capacity and backup file candidates in conventional
  top-level directories. Classifies command lines without printing them. Does
  not run application commands, query the database or change server state.
  Candidate backup files are not proof of consistent or recoverable backups;
  an empty candidate list is not proof that no backups exist elsewhere.

scripts/deployment/Install-DeploymentNode.ps1
  Administrator-only, one-time copy of existing Node 22.23.0 and its bundled
  npm into SUPREME-Deploy/runtime/node-v22.23.0. Refuses to replace an existing
  target, rejects source links, verifies the copied executable and versions,
  backs up server.json and configures explicit nodePath/npmPath. Uses inherited
  protected workspace ACLs; no profile, machine PATH or live app is modified.
  Upgrading this pinned runtime later requires a reviewed administrator action.
